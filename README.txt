
Extreme value distribution project
==================================

Blueprint via upstream: https://kkytola.github.io/ExtremeValueProject/

This is my fork of https://github.com/kkytola/ExtremeValueProject

My goal is to formalise
`AffineIncrEquiv.homomorphism_from_Real_characterization` and its
dependencies for my BSc thesis. All required results have already been
formalised on some branches, and they will appear on the main branch
once they are accepted to upstream.

In addition this repository contains a formalised counterexample
which proves the existence of a nonlinear additive real function.
It can be found as `lemma not_linear_of_additive` in
`ExtremeValueProject/OneParameterAffine.lean` on branch
`kandi-counterexample`.
